# M2A3_636015
HTML semántico + Validación W3C 
En esta actividad cambie varias etiquetas de <div> por etiquetas semánticas segun su funcion para darle significado a cada parte del HTML, como <header>, <nav>, <main>, <article>, <aside> y <footer>.
También para el texto usamos <time>, <q>, <abbr> y <address>, esto sirve para pasar de un <div> genérico a que describan las función de cada contenido.
Al final se valido el código con W3C y no tuvo errores ni advertencias.
